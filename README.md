# Retorno Logístico
Landing estática HTML/CSS/JavaScript. Bibliotecas locales: GSAP, ScrollTrigger y Lenis (assets/vendor); integridad registrada en vendor-manifest.json.

Node.js >=20. Comprobación: npm run check. Compilación: npm run build. Publicar sólo dist/.

Configurar SITE_URL con el origen HTTPS definitivo antes de compilar para producción. Sin SITE_URL el build lleva noindex y robots Disallow.

Consultar CORRECCIONES.md para cambios, pruebas y pendientes, especialmente privacidad y envío de correo.
